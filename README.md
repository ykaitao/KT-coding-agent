# KT-coding-agent: Autonomous Codebase Architecture & Optimization Agent

An enterprise-grade, multi-agent framework designed to autonomously analyze, optimize, and maintain complex application codebases. By launching a hierarchical swarm of specialized sub-agents, this system bridges the gap between static analysis, intelligent system design, and automated software engineering.

## 🚀 Core Features

### 1. Multi-Dimensional Deep Scanning Swarm
Instead of simple regex patterns, the framework orchestrates a swarm of domain-specific sub-agents to analyze your codebase using Abstract Syntax Tree (AST) parsing and runtime context:
* **Code Health & Optimization:** Identifies logic bugs, security vulnerabilities (SAST/DAST metrics), redundant logic, and performance bottlenecks.
* **System Architecture & Data Modeling:** Evaluates database schemas, index strategies, API boundary efficiency, and architectural patterns against system design best practices.
* **FinOps & Resource Attribution:** Scans for structural inefficiencies driving up cloud compute, data egress, database I/O, and LLM token usage.
* **UI/UX Auditing:** Evaluates front-end code for accessibility (WCAG), user flows, visual performance, and structural layout optimizations.

### 2. Autonomous Issue Lifecycle Management
* **Deterministic Issue Generation:** Translates discovered gaps into highly structured, implementable, and isolated GitHub Issues containing clear definitions of done (DoD).
* **Orchestrated Implementation Pipeline:** Dynamically spins up a dual-agent workflow:
  * **Feature/Fix Agents:** Autonomously write deterministic, localized code patches.
  * **Peer-Review Agents:** Provide automated, multi-pass code reviews to enforce code style, maintainability, and safety before merging.

### 3. Cognitive Memory & Evolutionary Learning
* **Persistent Skill Synthesis:** Vectorizes successful problem-solving paths and refactoring strategies, storing them as a re-usable, dynamic skill library to continuously reduce future agent latency and token cost.
* **Long-Term Preference Anchoring:** Maintains a stateful profile of user architectural preferences, coding standards, and operational guardrails to prevent regressions or out-of-bounds code generation.

### 4. Deterministic Verification & Human-in-the-Loop (HITL)
* **Evidence-Based Engineering:** Every proposed patch is backed by automated test suites or verifiable proofs to eliminate hallucinations.
* **Proactive Context Gathering:** When encountering high-ambiguity trade-offs, the agent safely halts execution to consult the user—presenting a structured decision framework with prioritized options, rigorous trade-off matrices, and logical recommendations.
